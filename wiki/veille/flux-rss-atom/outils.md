## **Outils**

| Outil                                                                 | Description                                                                                                                  |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| [Aerion RSS Radio France](https://rss-rf.aerion.me/)                  | Permet de générer des flux enrichis pour les émissions et podcasts de Radio France.                                          |
| [Atlas des flux](https://atlasflux.saynete.com/)                      | Annuaire francophone regroupant de nombreux flux RSS classés par thèmes et sources.                                          |
| [Blogtrottr](https://blogtrottr.com/)                                 | Envoie par email les nouveaux éléments publiés dans un flux RSS ou Atom.                                                     |
| [Bridgy Fed](https://fed.brid.gy/)                                    | Passerelle reliant les sites Web, le Fediverse et Bluesky.                                                                   |
| [ByeDoom](https://byedoom.com/)                                       | Transforme les profils publics de nombreux réseaux sociaux en flux RSS.                                                      |
| [FetchRSS](http://fetchrss.com/)                                      | Transforme des pages Web en flux RSS, Atom, JSON ou CSV grâce à un éditeur visuel.                                           |
| [FiveFilters](https://www.fivefilters.org/)                           | Permet de créer des flux depuis des pages Web et de convertir des flux partiels en flux contenant les articles complets.     |
| [GetRSSFeed](https://getrssfeed.com/)                                 | Recherche le flux RSS d'un podcast, d'un site, de Spotify, Apple Podcasts, SoundCloud ou YouTube.                            |
| [Inoreader](https://www.inoreader.com/)                               | Lecteur RSS capable de détecter automatiquement les flux associés à un site ou une URL.                                      |

| [Kill the Newsletter](https://kill-the-newsletter.com/)               | Transforme les newsletters reçues par email en un flux Atom personnel.                                                       |
| [Morss.it](https://morss.it/)                                         | Transforme une page Web en flux RSS ou enrichit un flux avec le contenu complet des articles.                                |
| [OmniRSS](https://omnirss.com/)                                       | Convertit les podcasts Spotify en flux RSS utilisables dans un lecteur de podcasts classique.                                |
| [Open RSS](https://openrss.org/)                                      | Crée ou fournit des flux pour de nombreux sites et plateformes comme YouTube, Reddit, Bluesky, Facebook, Twitch ou Mastodon. |
| [RSS Feed ASAP](https://rssfeedasap.com/)                             | Extrait des flux RSS depuis des plateformes comme Spotify, YouTube, SoundCloud ou des blogs.                                 |
| [RSS Fusion](https://www.rss-fusion.com/)                             | Service permettant de fusionner et filtrer plusieurs flux RSS.                                                               |
| [RSS Gizmos](https://rssgizmos.com/)                                  | Collection d'outils pour créer, rechercher, tester et manipuler des flux RSS et OPML.                                        |
| [RSS Parrot](https://rss-parrot.net/)                                 | Transforme un flux RSS/Atom ou un site en compte Fediverse pouvant être suivi depuis Mastodon.                               |
| [RSS-Bridge](https://rss-bridge.org/)                                 | Application open source générant des flux RSS/Atom pour de nombreux sites Web.                                               |
| [RSSHub](https://github.com/DIYgod/RSSHub)                            | Génère des flux RSS pour de nombreux sites et services qui n'en proposent pas nativement.                                    |
| [SiftRSS](https://siftrss.com/)                                       | Crée un flux filtré à partir d'un flux RSS/Atom existant selon des règles personnalisées.                                    |
| [Sympli RSS Fusion](https://github.com/GreenEffect/Sympli-RSS-Fusion) | Application open source et auto-hébergeable permettant de fusionner et filtrer plusieurs flux RSS/Atom.                      |
| [The Lemmy Club](https://thelemmy.club/)                              | Instance Lemmy permettant notamment d'exploiter les flux RSS des communautés du Fediverse.                                   |
| [Twitch App Spot](https://twitchrss.appspot.com/)                     | Générateur de flux RSS pour suivre les diffusions et VOD de chaînes Twitch.                                                  |
| [TwitchRSS](https://twitchrss.com/)                                   | Génère des flux RSS permettant de suivre l'activité des chaînes Twitch.                                                      |
| [VimRSS](https://vimrss.com/)                                         | Propose notamment des outils pour convertir des chaînes YouTube et contenus Reddit en flux RSS.                              |

### **Archives**

Liste de différents service, permettant le mix & remix de flux rss / atom

* [\<opml>2\<html>](https://github.com/dburr/opml2html) : Cet outil vous propose de convertir un fichier au format OPML en une liste de site au format HTML plus facile à intégrer sur un site web, la blogroll d’un blog, ou une page de liens favoris.
* [MoonMoon](http://moonmoon.org/) : permet de compiler un ensemble de flux thématiques en une seule page
* [Wizardrss.com](http://www.wizardrss.com/) : pour dire merde deux fois aux flux rss tronqués
* [RSS2email](https://github.com/wking/rss2email): lire un flux sur sa boite mail (created by the late [Aaron Swartz](http://en.wikipedia.org/wiki/Aaron_Swartz))
* [RSS2IMAP](http://rss2imap.sourceforge.net/en/index.html) : sauvegarder les articles de flux RSS dans une boîte IMAP
* [RSS ToDoList](https://rsstodolist.eu/) : pour gagner du temps lors de l’ajout de flux rss dans vos reader
* [WebSite-Watcher](http://aignes.com/) : outil de veille old-school, à l’époque ou le flux rss était quasi-inexistant
