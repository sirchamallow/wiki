# Chromium

Chromium est le navigateur web libre qui sert de base à Google Chrome et à d'autres navigateurs.\
Le navigateur Chromium propose une interface légère et des options et extensions semblables à Chrome sans les outils de pistage de Google.&#x20;

Voici quelques navigateurs utilisant Chromium : Google Chrome, Vivaldi, Opera, Brave, Microsoft Edge, Opera
