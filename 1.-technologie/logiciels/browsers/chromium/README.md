# Chromium

Chromium propose une interface légère et des options et extensions semblables à Chrome sans les outils de pistage de Google. Voici quelques navigateurs utilisant Chromium : Google Chrome, Vivaldi, Opera, Brave, Microsoft Edge, Opera
