# Microsoft Store

### Avantages

Quelques avantages à utiliser le téléchagement/installation de logiciels depuis le Microsoft Store

* **Sécurité** : applications vérifiées par Microsoft → moins de malware
* **Installation simple** : téléchargement en un clic, sans configuration
* **Mises à jour automatiques** : toujours à jour sans intervention
* **Désinstallation propre** : pas de fichiers résiduels
* **Centralisation** : gestion des apps dans un seul outil
* **Moins de logiciels indésirables** : pas de bundles ou pubs cachées
