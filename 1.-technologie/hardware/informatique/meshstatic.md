### **Description** <a href="#description" id="description"></a>

ThinkNode M4 est une batterie externe multifonctionnelle qui reprend la fonction d'alimentation portable des batteries externes traditionnelles et qui intègre également un module de communication **Meshtastic**, la technologie de communication sans fil longue distance LoRa et un module GPS de haute précision.

Il intègre les modules **Semtech LR1110** (compatible avec la bande de fréquences 868-915 MHz), **Nordic nRF52840** et **GPS** pour garantir performance et fiabilité. Les appareils Meshtastic prennent en charge les réseaux maillés distribués sans passerelle ni connexion Internet. Fonctionnant comme des nœuds interconnectés, ils étendent automatiquement la couverture. La communication bidirectionnelle est assurée, incluant la messagerie instantanée et le partage de position, répondant ainsi à divers besoins de communication, qu'il s'agisse de liaisons point à point ou de diffusion. Meshtastic est ainsi particulièrement adapté aux opérations sur le terrain, aux situations d'urgence et aux environnements sans réseau, offrant aux utilisateurs des garanties de communication stables et fiables.

### Usage <a href="#usage" id="usage"></a>

#### Bouton marche/arrêt <a href="#power-button" id="power-button"></a>

* **Appuyez légèrement** : pour réveiller l’appareil ou activer la lumière.
* **Appui bref pendant 1 seconde** : active successivement l’appareil, le niveau d’éclairage 1, le niveau 2, le niveau 3, puis l’éteint.

#### Touche de fonction LoRa <a href="#lora-function-key" id="lora-function-key"></a>

* **Appui long de 3 secondes** : le voyant LoRa clignote trois fois, plaçant l’appareil en mode veille tout en préservant l’alimentation du microcontrôleur et de l’horloge temps réel. Relâchez pour activer le mode veille ; tous les voyants s’éteignent alors.
* **Appui long pendant 10 secondes** : Connectez-vous à VBUS et maintenez la pression pendant plus de 10 secondes pour réinitialiser l'appareil (le voyant LoRa clignote trois fois, lumière rouge).
* **Double-clic** : Désactive ou active toutes les fonctions sauf le fonctionnement de l’émetteur-récepteur LoRa (par exemple, GPS, température/humidité).
* **Un seul clic** :

a. Un seul clic : en mode veille, cliquez pour activer la fonctionnalité LoRa de l’appareil ;

b. En mode opérationnel, met à jour les informations de localisation du nœud/périphérique

* **Appui long** : Appuyez longuement sur le bouton de réinitialisation de la carte mère pendant 20 secondes pour faire glisser le firmware dans la lettre de lecteur (G:).

#### Effets des voyants lumineux <a href="#indicator-light-effects" id="indicator-light-effects"></a>

**Rouge** :

* **Mise sous tension/initialisation** : voyant fixe après 3 clignotements rapides ; clignotements rapides, voyant fixe
* **Appairage Bluetooth** : clignotement lent (1 Hz) pendant l’appairage ; le Bluetooth s’active automatiquement à la mise sous tension (nécessite la saisie d’un code d’appairage).
* **Appairage Bluetooth réussi** : voyant fixe après 3 clignotements rapides, clignotements rapides (5 Hz)
* **Échec du jumelage Bluetooth** : clignote 5 fois (2 Hz)

**Bleu** :

* **Transmission/réception de données** , appareil envoyant ou recevant des données LoRa, clignote rapidement (5 Hz)
* **Positionnement en cours** , acquisition des coordonnées GPS, effet lumineux de respiration : 1 s d’apparition progressive + 1 s de disparition progressive
* **Positionnement réussi** , position GPS de l'appareil acquise, impulsion courte : 0,1 s activée / 2 s désactivée

### Appairage <a href="#android-appversion-2630" id="android-appversion-2630"></a>

1. Lorsque l'appareil `Meshtastic_xxxx` est recherché, appuyez pour entrer en mode de couplage.
2. Entrez ce code **`123456`** sur votre téléphone portable (le code PIN par défaut
3. Configurer la fréquence LoRa : appuyez sur l’icône `Paramètres`, sélectionnez `Configuration radio`, puis l’option `LoRa`. Faites défiler vers le bas jusqu’à la colonne `Ajouter` et saisissez la valeur souhaitée dans le champ `Fréquence de couverture (MHz)`.
4. Réglez la fréquence LoRa : `915.0`
